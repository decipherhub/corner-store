Demo guide

버튼만 따라가며 정상 체결과 컴플라이언스 차단을 모두 시연할 수 있습니다.

정상 RFQ 거래

  1. Check & prepare demo로 배포·백엔드·maker 상태를 확인합니다.
  2. Request firm quote로 Meridian의 실제 서명 quote를 받습니다.
  3. Review this quote에서 금액·nonce·서명을 확인합니다.
  4. Execute selected quote로 Router를 통해 체결합니다.
  5. Operator → Refresh snapshot에서 RFQSettled 이벤트를 확인합니다.

Security demo

  1. 1 · Create test quote로 승인 상태에서 quote를 저장합니다.
  2. 2 · Revoke maker & execute로 maker를 취소한 뒤 같은 quote를 제출합니다.
  3. RFQMakerNotApproved 차단 결과를 확인합니다.
  4. Restore maker로 다음 시연을 준비합니다.

실제 데이터와 fixture

  • Live: 배포 주소, manifest, maker 승인, Meridian quote, Router 거래, indexed events, live rate.
  • Fixture: Mock TA, BUIDL-like 자산, Falcon/Nomos preview, 차트 곡선·spread·통계.
  • Fixture quote는 비교용이며 선택하거나 체결할 수 없습니다.

시작과 종료

  • 루트에서 scripts/demo.sh --profile buidl-like를 실행합니다.
  • 출력된 http://127.0.0.1:8790을 엽니다.
  • launcher 터미널에서 Ctrl-C를 누르면 모든 데모 프로세스가 종료됩니다.
