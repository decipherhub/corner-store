Presenter guide

규제 RFQ 데모 순서

01

주입 데이터 확인

환경 준비 버튼으로 scenario JSON의 사용자·자산·정책 fixture를 온체인에 반영합니다.

02

비적격 차단

비적격 사용자의 Pre-check 실패와 Router 최종 거부를 확인합니다.

03

적격 체결

적격 사용자로 새 quote를 요청하고 정상 체결합니다.

04

시간 만료

Admin에서 만료 데모를 준비하고 quote를 받은 뒤 시간을 경과시켜 같은 quote가 최종 검사에서 거부되는지 확인합니다.

중요 quote는 taker 주소에 묶이며 Pre-check는 보장이 아닙니다. 체결 시 Router가 최신 claim freshness와 maker 정책을 다시 검사합니다.
